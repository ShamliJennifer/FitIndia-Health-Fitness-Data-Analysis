# FitIndia-Health-Fitness-Data-Analysis
# 🏋️ FitIndia Health & Fitness Data Analysis

A Python-based data analysis project focused on understanding health, fitness, workout behavior, and membership patterns among FitIndia members.

---

## 📌 Project Overview

The **FitIndia Health & Fitness Data Analysis** project analyzes member health, fitness, workout, and membership data using Python.

The project follows a complete data analysis workflow, including:

* Data loading
* Data cleaning and preprocessing
* Missing-value handling
* Statistical analysis
* Exploratory Data Analysis (EDA)
* Data visualization
* Business insight generation

The goal is to transform raw fitness data into meaningful insights that can help fitness centers understand member behavior and make data-driven decisions.

---

## 🎯 Objectives

* Clean and preprocess the raw fitness dataset.
* Identify and handle missing or inconsistent data.
* Perform descriptive statistical analysis.
* Analyze member demographics and fitness behavior.
* Identify patterns in workout activity and membership.
* Create meaningful visualizations.
* Generate useful business insights from the data.

---

## 📊 Dataset

The dataset contains information about **180 FitIndia members**.

### Dataset Features

| Feature               | Description                                  |
| --------------------- | -------------------------------------------- |
| Member ID             | Unique identification number                 |
| Member Name           | Name of the member                           |
| City                  | Member's city                                |
| Zone                  | Geographic zone                              |
| Gender                | Gender of the member                         |
| Age                   | Age of the member                            |
| Membership Type       | Type of fitness membership                   |
| Activity Level        | Member's activity level                      |
| Occupation            | Member's occupation                          |
| Monthly Fee           | Monthly membership fee                       |
| Calories Burnt        | Calories burned during workouts              |
| Workout Sessions      | Number of workout sessions                   |
| Preferred Activity    | Preferred fitness activity                   |
| Payment Mode          | Method of membership payment                 |
| Days Since Last Login | Number of days since the member's last login |
| Health Rating         | Health/fitness rating                        |
